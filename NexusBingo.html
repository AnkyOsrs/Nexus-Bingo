Discord Webhooks

Referee channel

Used for any team with no webhook of its own. Leave blank to post nothing for those teams. Handy for a general #bingo channel that sees everything.
Discord → Server Settings → Integrations → Webhooks → New Webhook → pick the channel → Copy Webhook URL.

Live Sync (Firebase)

Without this, every visitor sees their own copy stored in their own browser. With it, everyone who opens your link sees one live board that updates in real time.
Anything you like, no spaces. Different IDs = different boards on the same Firebase project.
Paste the config object from Firebase → Project settings → Your apps. It must include databaseURL. These keys are public identifiers, not secrets — it is safe for them to be in the page.
To share with your clan, this config has to live in the file itself, not just in your browser. Save it here, then use Import / Export → Export board file — the downloaded HTML has the config baked in. Host that file and everyone gets the live board.

Import / Export
