Teams

Removing a team deletes its progress. Colours are used for the standings and the stripe along the bottom of each completed tile.
Leader PINs. Give a team its own PIN and it unlocks leader mode for that team only — they can watch every board but can only mark their own, so nobody edits the wrong team by accident. Leave it blank and they use the shared leader PIN, which still opens every team (handy for you or a head organiser). PINs are stored hashed, so an existing one can't be shown back — type a new one to replace it, or use Clear PIN.

Discord Webhooks

Stored in this browser only. Webhook URLs are never written into the board file and never uploaded to sync, so nobody who opens your board link can read them and spam your channels. Each team leader pastes their own team's URL here once, on the machine they run the board from.

Referee channel

Live Sync (Firebase)

This board already has a Firebase project built into the file, so everyone who opens the link is on the same live board with no setup. You only need the boxes below to point it at a different project.
Anything you like, no spaces. Different IDs = different boards on the same Firebase project.
Paste the config object from Firebase → Project settings → Your apps. It must include databaseURL. These keys are public identifiers, not secrets — it is safe for them to be in the page.
A config entered here applies to this browser only. To change the project for everyone, edit DEFAULT_FIREBASE near the top of the script in the HTML file, or save it here and use Import / Export → Export board file to bake it into a fresh copy.
